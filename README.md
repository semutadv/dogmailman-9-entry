"The Dog Reviews the Mailman":

> One star for the mailman: smells like other people's houses, rings the bell like he owns it, and has never once brought me a single treat.

## Program notes

Running `main.ts` with Node clears the output directory's contents and
saves the review as `entry.txt` for the length gate and the pairwise judge.
